Current: –. The new firmware (ps-hid-bridge.uf2) is written to the second slot and only kept after it started successfully. If it does not start properly, the board returns to the previous version after a restart.

Restart

The board restarts. Input is interrupted for a few seconds.

Factory reset

Erases password, key and network settings. Afterwards the factory password applies again and the app needs a new key. Alternatively: hold the BOOTSEL button on the board for 5 seconds.
